## The 5 Phases

### Phase 1: Business Process Automation — $15-25K
**Timeline:** 4-8 weeks
**Deliverable:** 5+ automated workflows in production, local LLM inference, document automation, intelligent routing

**What gets built:**
- Local LLM deployment (Ollama) running on your hardware
- n8n workflow automation engine with 5+ production workflows
- MCP integration layer connecting AI to your existing systems
- Docker containerized infrastructure with monitoring and health checks
- Document automation (invoices, reports, compliance docs generated automatically)
- Intelligent email/inquiry classification with draft response generation
- Staff training on workflow maintenance and extension

**Exit criteria:** Internal team can maintain and extend workflows independently. Manual processing time reduced 50-70% across automated processes.

**What this looks like in practice:**
A remodeling company receives the same types of emails repeatedly — scheduling, billing, design questions, complaints. Phase 1 deploys an AI that classifies every incoming email, drafts a response in the company's voice, and routes it to the right person. What took 45 minutes of manual drafting now takes 90 seconds of review. The company's internal team learns to maintain and extend the workflows themselves — no ongoing consultancy required.

### Phase 2: Autonomous IT Operations — $20-35K
**Timeline:** 6-12 weeks
**Deliverable:** AI agent that triages tickets, guides technicians, and executes fixes with human approval

**What gets built:**
- AI agent (Hermes Agent framework) integrated with your ticketing system (Jira, etc.)
- Real-time ticket triage: category, urgency, complexity classification
- Technician guidance: fix suggestions, SOP linking, similar ticket matching
- MDM fleet integration: visibility and control over all endpoints (Windows/Linux/Android/Mac)
- Scripted fix delivery with human-in-the-middle approval — agent executes fixes on target machines
- Automated SOP generation: every resolved ticket becomes documented institutional knowledge
- Knowledge base that compounds with every resolution

**Exit criteria:** 50%+ of tier-1 tickets resolved without senior technician involvement. SOP library covering all common issues.

**What this looks like in practice:**
A religious organization with multiple campuses needs IT support across locations. Phase 2 deploys an AI agent that triages every support request — understanding the campus network topology, application stack, and common issues. The agent guides staff toward resolution, executes scripted fixes with human approval, and generates documentation for every resolved issue. The IT team gains an always-on partner that handles triage while they focus on higher-value work.

### Phase 3: Autonomous Security Operations — $25-50K
**Timeline:** 8-16 weeks
**Deliverable:** Full SOC replacement — SIEM, AI triage, automated containment and remediation

**What gets built:**
- Elastic Stack SIEM aggregating logs, telemetry, and security events from every system
- pfSense/Sophos firewall integration — AI reads traffic flows, modifies rules with human approval
- Endpoint agents on every machine: isolation, process killing, file quarantine, patch deployment
- AI-powered triage: false positive filtering, threat context surfacing, recommended response
- Automated containment workflow: detect → analyze → contain → plan → approve → remediate → document

**Exit criteria:** Mean time to detect (MTTD) under 5 minutes for critical threats. Mean time to respond (MTTR) under 30 minutes with human approval.

**What this looks like in practice:**
A financial services firm needs 24/7 security monitoring but can't afford a full SOC team. Phase 3 deploys an AI-powered security operations center that aggregates logs from every system, triages security events with AI (filtering false positives, surfacing genuine threats), and executes containment with human approval. The firm gets SOC-level capability at a fraction of the cost — and all data stays on their infrastructure.

### Phase 4: Proactive Infrastructure — $10-20K
**Timeline:** 4-8 weeks
**Deliverable:** Predictive monitoring, self-healing systems, proactive maintenance

**What gets built:**
- Predictive monitoring: AI analyzes system metrics to predict failures before they happen
- Self-healing infrastructure: automated response to common infrastructure issues (disk full, service down, certificate expiring)
- Printer fleet management: AI monitors printer status, predicts maintenance needs, auto-orders supplies
- Network optimization: AI analyzes traffic patterns and recommends configuration changes
- Capacity planning: AI predicts resource exhaustion and recommends scaling actions

**Exit criteria:** Infrastructure-related incidents reduced 60%+. Mean time to resolution for infrastructure issues under 15 minutes.

### Phase 5: AI-Powered ERP Tooling — $20-40K
**Timeline:** 8-16 weeks
**Deliverable:** Natural language interfaces on legacy ERP systems

**What gets built:**
- Natural language query interface: "Show me all outstanding invoices over $10K from the Pacific Northwest region"
- AI-powered data entry: extract structured data from unstructured documents (PDFs, emails, images) and insert into ERP
- Automated reporting: generate custom reports from ERP data using natural language specifications
- Workflow automation: trigger ERP actions from AI-processed inputs (approve purchase order, update inventory, close ticket)
- Legacy system modernization: AI bridges the gap between modern expectations and legacy interfaces

**Exit criteria:** ERP query time reduced 80%+. Manual data entry reduced 60%+. Staff can retrieve any ERP data through natural language.
